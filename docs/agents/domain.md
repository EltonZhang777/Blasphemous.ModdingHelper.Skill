# Domain Docs

This is a single-context repository.

## Before exploring

Read `CONTEXT.md` at the repository root when it exists.

Read relevant ADRs under `docs/adr/` when they exist.

If these files do not exist, proceed without creating them unless domain modeling resolves terms or decisions that need recording.

## Use the glossary vocabulary

Use the terminology defined in `CONTEXT.md` for issue titles, proposals, hypotheses, and tests.

## Flag ADR conflicts

If a proposal contradicts an existing ADR, identify the ADR explicitly instead of silently overriding it.
