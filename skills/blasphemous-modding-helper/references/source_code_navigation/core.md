# Core components

List of important frameworks, managers, handlers, and core components in Blasphemous source code.

---

## Framework.Managers
namespace that contains all the important manager classes in Blasphemous, for example
- `LevelManager`
- `LocalizationManager`
- `AchievementsManager`

## Framework.Managers.Core
Singleton class that handles most core game logic. Holds an instance to almost all the manager classes.
